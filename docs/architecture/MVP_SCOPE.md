# MVP Scope — Part 1

## In scope for initial validated beta
- Responsive PWA, accessible login and user settings when account milestone is reached.
- Public Spot/Futures symbol discovery, candle history and live updates with freshness/error indicators.
- Interactive licensed candlestick chart, selected technical indicators, chart drawings and basic layouts.
- Evidence-backed AI Trade Setup Analyzer with LONG/SHORT/WAIT, entry zone, targets, stop, invalidation, expiry and explanation.
- Separate Spot and Futures signal bots; explicit deterministic risk gate.
- Separate persisted virtual Spot and Futures portfolios, 1000 USDT each; confirmations, transaction ledger, session history.
- Watchlists, scanner, basic alerts, historical backtesting with fees/slippage and clear limitations.
- Automated tests, security controls, audit logs, observability and deployment readiness gates.

## Deferred / gated
- Native mobile apps; advanced multi-chart layouts and extensive drawing/indicator catalog; paid subscription checkout and billing; production deployment; any feature lacking licensing or safety validation.
- Never in scope: real exchange order placement, real trading API keys, live account balances, or exchange-authenticated trading flows.

## Definition of done
Feature acceptance criteria, code review, automated tests with actual results, security/regression review, documented limitations, user approval before advancing.
